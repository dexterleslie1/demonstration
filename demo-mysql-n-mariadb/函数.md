## `if`函数

`if(value,t,f)`：如果`value`为`true`则返回`t`，否则返回`f`。

```sql
mysql> select if(true,'yes','no');
+---------------------+
| if(true,'yes','no') |
+---------------------+
| yes                 |
+---------------------+
1 row in set (0.00 sec)

mysql> select if(false,'yes','no');
+----------------------+
| if(false,'yes','no') |
+----------------------+
| no                   |
+----------------------+
1 row in set (0.00 sec)
```

## `ifnull`函数

`ifnull(value1,value2)`：如果`value1`不为空，则返回`value1`，否则返回`value2`

```sql
mysql> select ifnull('v1','v2');
+-------------------+
| ifnull('v1','v2') |
+-------------------+
| v1                |
+-------------------+
1 row in set (0.00 sec)

mysql> select ifnull(NULL,'v2');
+-------------------+
| ifnull(NULL,'v2') |
+-------------------+
| v2                |
+-------------------+
1 row in set (0.00 sec)
```

## 自定义函数

>https://stackoverflow.com/questions/16737910/generating-a-random-unique-8-character-string-using-mysql

- 创建自定义函数

  ```sql
  DELIMITER $$
  
  DROP FUNCTION IF EXISTS `randStr`$$
  
  CREATE FUNCTION `randStr`(length SMALLINT(3)) RETURNS varchar(1024) CHARSET utf8 NO SQL
  begin
      SET @returnStr = '';
      SET @allowedChars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
      SET @i = 0;
  
      WHILE (@i < length) DO
          SET @returnStr = CONCAT(@returnStr, substring(@allowedChars, FLOOR(RAND() * LENGTH(@allowedChars) + 1), 1));
          SET @i = @i + 1;
      END WHILE;
  
      RETURN @returnStr;
  END$$
  DELIMITER ;
  ```

- 调用自定义函数

  ```sql
  select randStr(8);
  ```

## ROW_NUMBER、RANK、DENSE_RANK

在 MariaDB（从 10.2 版本开始支持）中，`ROW_NUMBER()`、`RANK()` 和 `DENSE_RANK()` 是最常用的三个窗口函数，主要用于为结果集中的行分配序号或排名。它们的核心区别在于**如何处理相同值（并列）的情况**以及**排名序号是否连续**。

以下是这三个函数的详细对比与用法指南：

### 1. 核心区别对比

| 函数             | 遇到相同值（并列）时       | 后续排名是否连续（跳号）            | 典型应用场景                           |
| :--------------- | :------------------------- | :---------------------------------- | :------------------------------------- |
| **ROW_NUMBER()** | 不并列，强制分配唯一序号   | 连续（1, 2, 3, 4...）               | 数据去重、分页、取每组前N条记录        |
| **RANK()**       | 并列（相同值获得相同排名） | **不连续，会跳号**（1, 1, 3, 4...） | 竞赛排名、需要体现“击败了多少人”的场景 |
| **DENSE_RANK()** | 并列（相同值获得相同排名） | **连续，不跳号**（1, 1, 2, 3...）   | 等级划分、分档评级（如A/B/C档）        |

### 2. 基础语法结构

这三个函数的语法结构基本一致，必须配合 `OVER()` 子句使用：

```sql
函数名() OVER (
    [PARTITION BY 分组字段]  -- 可选：按字段分组，排名在每个组内独立计算
    ORDER BY 排序字段 [ASC|DESC] -- 必需：指定排名的依据
) AS 别名
```

### 3. 实战示例演示

假设有一张员工薪资表 `employees`，数据如下：

| emp_name | department | salary |
| :------- | :--------- | :----- |
| Alice    | HR         | 8000   |
| Bob      | HR         | 8000   |
| Carol    | HR         | 7000   |

使用以下 SQL 语句同时调用这三个函数：

```sql
SELECT
    emp_name,
    department,
    salary,
    ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC) AS row_num,
    RANK()       OVER (PARTITION BY department ORDER BY salary DESC) AS rank_num,
    DENSE_RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS dense_rank_num
FROM employees;
```

**查询结果：**

| emp_name | department | salary | row_num | rank_num | dense_rank_num |
| :------- | :--------- | :----- | :------ | :------- | :------------- |
| Alice    | HR         | 8000   | 1       | 1        | 1              |
| Bob      | HR         | 8000   | 2       | 1        | 1              |
| Carol    | HR         | 7000   | 3       | **3**    | **2**          |

**结果解析：**
*   **ROW_NUMBER()**: Alice 和 Bob 薪资相同，但函数强制给了 1 和 2，Carol 顺延为 3。
*   **RANK()**: Alice 和 Bob 并列第 1 名，由于占用了两个名额，Carol 直接跳到了**第 3 名**。
*   **DENSE_RANK()**: Alice 和 Bob 并列第 1 名，Carol 紧接其后，排名为**第 2 名**，排名数字是紧密连续的。

### 4. ⚠️ 常见避坑指南

1.  **不可直接在 WHERE 中过滤窗口函数**：
    窗口函数是在 `SELECT` 阶段执行的，而 `WHERE` 在 `SELECT` 之前执行。因此，`WHERE RANK() OVER(...) <= 3` 这种写法会直接报错。
    **正确做法**：必须使用子查询或 CTE（公用表表达式）进行包裹。
    ```sql
    WITH RankedData AS (
        SELECT *, RANK() OVER (ORDER BY salary DESC) as rnk
        FROM employees
    )
    SELECT * FROM RankedData WHERE rnk <= 3;
    ```

2.  **ORDER BY 字段必须稳定**：
    当使用 `ROW_NUMBER()` 且排序字段存在大量重复值时，相同值的行号分配顺序是不确定的（取决于底层执行计划）。如果需要稳定的分页或去重，建议在 `ORDER BY` 中补充一个唯一字段（如主键 `id` 或时间戳），例如：`ORDER BY salary DESC, id ASC`。

3.  **注意 NULL 值的排序行为**：
    在 MariaDB 中，默认情况下 `NULL` 值在升序排序时会被排在最前面（NULLS FIRST）。如果业务上需要将空值排在最后，可以通过 `ORDER BY col ISNULL, col ASC` 等方式进行兜底控制。
